# 数据与标注（组员 A）

把自采图片放进 `raw/`，标注导出的 mask 放进 `exports/`。类别由 `categories.yaml` 统一维护，其他成员只读。

## 目录

```
data/
  raw/                  # 原始手机拍摄图（git 忽略）
  exports/              # 标注后按 masks/ 树组织
    images/xxx.jpg
    masks/xxx.png       # 单通道，0 背景，1..N 类别
  annotations/          # Label Studio 原始导出（git 忽略）
  splits/               # 由 scripts/split_dataset.py 生成
  categories.yaml       # 类别清单（手工维护）
```

## 类别约定

- 0 固定为背景；1..N 为前景类别。
- 首期 5 类：`meat`、`fish`、`vegetable`、`rice`，加 `other` 兜底（见下节）。
- 每类建议 40-60 张真实照片，先保闭环再扩容。
- 255 表示 ignore：真的拿不准的区域，评测时自动排除。有 `other` 兜底后不要滥用。

## 4 类之外的食物怎么处理

`meat`/`fish`/`vegetable`/`rice` 是**我们要评测的目标类**，不是「照片里允许出现的全部东西」。
食堂打菜必然会混进鸡蛋、豆腐、土豆丝、汤、水果，规则如下：

- 明显是食物、但不属于 1-4 类的 → 标 `5 other`。
- 不是食物（餐具、包装袋、饮料瓶、纸巾、桌布、桌面）→ 不标，当背景 0。
- **绝不要把「其他食物」当背景标。** 当背景等于告诉模型「土豆丝是背景」，部署时它就会把土豆丝抠成背景 —— 那不是模型的失败，是标注教出来的。

混合菜（青椒炒肉丝、番茄炒蛋这种糊在一起分不开的）：

- 不要硬拆成「肉」+「菜」两块，拆不准反而制造噪声。
- 整份按**主导属性**归一类；真的说不清就标 `other`。
- 同一道菜在所有照片里必须归同一类。建议维护一份「菜名 → 类别」对照表贴在本节下面。

什么时候该加新类别：

- 某类食物在你们数据里占比超过 10%（比如鸡蛋、土豆）→ 别塞 `other`，直接加成类别 6。
- `other` 占比超过 20% → 说明类别体系选错了，要重新讨论（例如改成「主食 / 荤菜 / 素菜」，而不是按食材分）。

评测口径（必须写进报告）：

- 主指标只报 1-4 类（mIoU / Dice / 边界 F1）。
- `other` 单独报一栏，不混进主指标。
- 背景单独报一栏或直接不报。
- `255 ignore` 区域完全不参与计算，只在真的说不清时用。

## 原始图片格式要求（组员 A 的照片必须符合）

- 格式：`.jpg`（首选）或 `.png`；不要 iPhone 默认的 `.heic`，不要 `.raw`/`.dng`。
- 尺寸：保留手机原图，或统一缩到长边 1024-2048；同一批不要混用纵横比。
- 命名：`<场景>_<日期>_<序号>.jpg`，例如 `canteen_20261020_001.jpg`。
- 放哪儿：直接给组员 A 的**本地** `data/raw/<场景>_<日期>/`，例如 `data/raw/canteen_20261020/`。
- 注意：`data/raw/` 在 `.gitignore` 里，**照片不进 git**，用网盘/微信群传压缩包。
- 拍摄要求：不要滤镜、不要美颜、不要裁剪拼接；同一盘菜不要连拍几十张凑数。
- 不要拍人脸；同一张照片里尽量有 3-8 个可标注的食物实例（一张图多个 mask 才有价值）。

## 标注取舍规则

核心原则：**不追求标全，追求标得一致**。同一张图换个人重标一遍，结果应该基本一样。

- 上限：一张图最多标 15 个实例。超过就按像素面积从大到小取前 15 个，其余不标。
- 下限：可见面积不到整图的 0.5%，或长/宽任一边小于 20px 的，不标。
- 遮挡：被别的食物压住、可见部分不到一半的，不标。
- 类别外：餐具、包装袋、饮料瓶、纸巾、桌布 —— 一律当背景。除非你们把该类别加进 `categories.yaml`。
- 拿不准：标成 255（ignore），评测时自动排除，不算标错。
- 粘连：两个食物真的糊在一起分不开时，只标可见轮廓，不要脑补边界。
- 价值下限：一张图连 3 个实例都凑不出，这张图价值低 —— 留作「稀疏/失败样本」，别塞进主训练集。

操作上：Label Studio 里**没画到的区域自动算背景 0**，所以「不标」就等于「当背景」，不需要额外操作。

谁标：同一张图的所有 mask 必须由**同一个人一次标完**，不要两个人分着标同一张图，边界风格不一致会污染数据。

## 标注步骤

1. 本地或 Docker 启动 Label Studio。
2. 用 brush/rectangle 标出 mask 模板。
3. 导出 PNG mask，统一成 `images-id.png`，放进 `exports/masks/`。
4. 用 `scripts/convert_masks.py` 把 mask 按类别拆成树，或直接按 0..N 约定保存。
